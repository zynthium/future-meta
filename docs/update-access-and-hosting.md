# 更新访问与 GitHub 托管

客户端大文件使用不可变 Release 附件，固定 manifest 与轻量检查状态使用独立 `data` 分支的 raw URL。无需 Pages、线上 SQLite、原件 bootstrap 或跨仓库凭据。

每个合法交易时段只发起一轮更新；周末不访问交易所，普通早盘不补跑。工作日夜盘前和法定休市后首个早盘的具体门禁、重试、重定向及浏览器截止控制，见 [部署说明](deployment.md#交易所访问窗口)。

一轮更新需要读取多份日参数和现行规则资料，并加载大商所页面资源。规则文档按 URL 去重并支持条件请求；不能把一轮更新误称为一个 HTTP 请求。目录或文档出现无法解释的变化时失败，不继续推进核验日期。

数据没有变化时只提交检查状态；manifest 与客户端文件保持不变。GitHub raw 的 CDN 可能短暂保留旧索引，旧索引始终对应仍可下载的不可变附件。生产读回通过后才清理已被替换的数据版本。

历史证据只在本地保存；CI 临时原件不作长期云端归档。需要长期诊断原件时，应在本地执行独立采集并保存，不为日更重新引入大维护包。完整流程见 [部署说明](deployment.md)。
